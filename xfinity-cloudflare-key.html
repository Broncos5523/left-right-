Private Xfinity encryption key

Generate the 32-byte secret that Cloudflare needs to protect your new Xfinity pairings. Generated entirely in this iPhone browser.

Generate a new encryption key

This is for a fresh pairing setup. It cannot decrypt the old Firebase pairing tokens. Your existing boards and controller aren't changed.

Important: Don't paste the value into this chat, GitHub, or screenshots. Add it to Cloudflare as a Secret named TOKEN_ENCRYPTION_KEY, and save a private backup in your password manager. Never generate a replacement after pairing unless you intend to pair the boxes again.
  1. Tap Generate new private key.
  2. Tap Copy secret.
  3. Return to Cloudflare's Production → Add environment variable dialog.
  4. Key: TOKEN_ENCRYPTION_KEY. Value: paste the copied secret. Tick Secret.

This page makes no network calls for key generation and stores no secrets. You can inspect its source in your GitHub repository.
