Interpretation guide

Five active players is only a candidate signal. If those five change with substitutions across multiple samples, it becomes much more credible. A true inferred five-player lineup also requires reliable starters and a complete substitution sequence. If neither source supports exactly five, the report will say unverified rather than guessing. This page requires a browser with access to ESPN's unofficial Site API.
